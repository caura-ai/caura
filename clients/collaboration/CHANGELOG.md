# Changelog

Releases of the caura-bus collaboration clients (`caura-bus-core`,
`caura-bus-mcp`, `caura-bus-cli`, `caura-bus-adapter-sdk`), which ship in
lockstep at one version. Produced by release-please from Conventional Commits
under `clients/collaboration/` from `0.3.0` on.

## 0.3.0 (2026-10-08)

First release published to PyPI. `0.2.0` existed only as the version string of
unpublished preview builds.
