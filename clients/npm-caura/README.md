# caura

Convenience package for [Caura](https://caura.ai) — governed shared memory
for AI agent fleets. Re-exports
[`@caura/memclaw-client`](https://www.npmjs.com/package/@caura/memclaw-client),
the official TypeScript client.

```bash
npm install caura
```

```ts
import { Caura } from "caura";
```
